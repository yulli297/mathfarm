1. 학생 명단

한 줄에 한 명씩 번호,이름,비밀번호 로 적어요. 구글 시트에서 세 칸(번호·이름·비밀번호)을 복사해 붙여 넣어도 돼요.
학생은 번호 + 비밀번호로 들어와요. 학생의 농장은 번호로 구분하니, 학기 중에 번호를 바꾸면 새 농장이 돼요. 비밀번호를 바꾸면 그 학생은 다시 로그인해야 해요.

2. Apps Script(구글 시트)에서 쓰던 데이터 가져오기

지금까지 학생들이 키운 농장을 그대로 옮겨요. 명단을 먼저 저장한 다음 하세요. 이름으로 학생을 찾아서 연결해요(학생명단 탭의 이름과 똑같아야 해요).

  1. 구글 시트의 탭을 열고, 왼쪽 위 모서리 칸(A열 머리 왼쪽 빈칸)을 눌러 시트 전체를 선택 → Ctrl + C
  2. 아래 알맞은 칸에 Ctrl + V (첫 줄 제목은 같이 붙여도 돼요)
  3. 세 탭 모두 붙인 뒤 가져오기
농장데이터 탭
